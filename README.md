# Savannah Vasher — Personal Portfolio Website

A personal portfolio website highlighting my academic background at Louisiana State University, professional experience, leadership roles, and analytical project work. The site is built with clean semantic HTML5 and vanilla CSS, featuring an elegant navy, cream, and gold design that is fully responsive across desktop, tablet, and mobile devices.

**Live Website:** [https://savannahvasher.github.io/savannah-website/](https://savannahvasher.github.io/savannah-website/)

---

## Website Structure & Pages

1. **Home (`index.html`)**
   - **Hero Section:** Personal introduction and quick navigation to featured pages.
   - **About Section:** Background on my studies in Information Systems and Analytics and Internal Auditing at LSU's Roger Hadfield Ogden Honors College.
   - **Skills Section:** Categorized capabilities in Data & Business Intelligence (Power BI, Excel), Automation (Power Automate), and Professional Strengths.
   - **Experience Section:** Career timeline showcasing roles at the LSU Office of Business Student Success, TxDOT Maritime Division, and leadership positions with Alpha Kappa Alpha Sorority, Inc. and Jack and Jill of America, Inc.
   - **Contact Section:** Direct contact details and a direct email communication form.

2. **Resume (`resume.html`)**
   - Displays my complete curriculum vitae directly on the page, formatted for clear screen reading on both mobile phones and desktop displays.
   - Includes education (GPA: 3.58, honors, and coursework), professional work history, leadership positions, core technical skills, and campus involvement.
   - Features a built-in **Print / Save as PDF** utility optimized via CSS print stylesheets (`@media print`).

3. **TxDOT Project Case Study (`project.html`)**
   - A detailed operational case study covering my work as an Intern Support Technician for the Texas Department of Transportation (TxDOT) Maritime Division within Business Operations.
   - Outlines the initial problem, my contributions organizing records across financial documents and travel expenses, tools utilized (Excel and pivot tables), the operational value delivered, and key lessons learned.

---

## Design & Technology Stack

- **HTML5:** Semantic markup, accessible labeling, and relative linking designed for GitHub Pages.
- **Vanilla CSS3:** Custom properties for consistent navy, cream, and gold palette, CSS Flexbox, CSS Grid layouts, and custom media queries for seamless mobile responsiveness.
- **Zero Frameworks:** Lightweight, fast-loading architecture without external dependencies or heavy frameworks.

## Learning Reflection

When the agent started my website at localhost:8080, I did not initially understand how that differed from my GitHub Pages link. I asked the agent to explain the difference and learned that localhost refers to the computer being used, so another person entering that address would not reach my website. GitHub Pages hosts my website online, allowing others to visit its public link even when my laptop is turned off. This helped me understand the difference between local testing and public hosting.
